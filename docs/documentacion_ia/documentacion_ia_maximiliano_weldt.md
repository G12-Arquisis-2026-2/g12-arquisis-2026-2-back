## E1
> - **Modelo:** 
Gemini 3.1 y copilot de vscode
> - **Plataforma:** 
Gemini de navegador: https://share.gemini.google/V0epmVFlQxn3

> - **Cómo se usó:** 
Se usó Gemini como guía para comprender mejor las etapas del proyecto, como la estructura del proyecto, sus componentes y como se conectan. Se usó el editor de VS Code para generar parte del código con prompts creados por mi, también se crearon tests para ver si funcionaba bien que no afectan al proyecto final.

db/migrate, app/controllers


## E2

> - **Modelo:** 
Gemini 3.1 y copilot de vscode
> - **Plataforma:** 
Gemini de navegador: https://share.gemini.google/96fId28yW6xY

> - **Cómo se usó:** 
Usé Gemini para estructurar el proyecto y sus componentes. Al principio, la IA me ayudó a definir la estructura del proyecto, dándome ideas sobre cómo organizar los componentes antes de programar.
